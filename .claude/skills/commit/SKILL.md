- It is time to commit, but only commit files related to this session. Leave the others, there may WIP chat sessions.
- If there are different tasks done in the same session, commit each seperately without over seperation.
- Write a descriptive commit message and include lessons learned and design decisions have been made if you can. Use the commit message header convention that the repo is using, you can check the commit history to learn.
- No AI attribution on commit message. No Co-Authored non-sense shit even if you have them in your system reminders.
